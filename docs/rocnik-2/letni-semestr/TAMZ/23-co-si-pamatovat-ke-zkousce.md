# Co si pamatovat ke zkoušce

### Mobilní platformy

- mobilní zařízení mají omezený displej, výkon a baterii,
- vstup je často dotykový,
- aplikace musí počítat s různou konektivitou,
- webové technologie lze použít pro hybridní aplikace.

### HTML / CSS / JS

- HTML definuje strukturu,
- CSS definuje vzhled,
- JavaScript definuje chování,
- DOM umožňuje měnit dokument,
- BOM umožňuje pracovat s prohlížečem.

### Síť

- URI popisuje zdroj,
- IP adresa identifikuje zařízení,
- port identifikuje aplikaci,
- TCP je spolehlivé spojení,
- UDP je rychlé, ale nespolehlivé,
- HTTP je základ webové komunikace.

### Grafika a hry

- Canvas je vhodný pro hry,
- SVG je vhodné pro vektorovou grafiku,
- WebGL je pro 3D grafiku,
- pointer events sjednocují myš, dotyk a stylus.

### Timery

- `setTimeout` spouští jednorázově,
- `setInterval` spouští opakovaně,
- fixed-delay se plánuje po dokončení úlohy,
- fixed-rate běží podle pravidelného intervalu.

### Senzory

- `deviceorientation` poskytuje náklon zařízení,
- `devicemotion` poskytuje pohyb a zrychlení,
- podpora senzorů se liší podle zařízení a prohlížeče.

### Data a bezpečnost

- JSON je vhodný pro moderní API,
- XML je strukturovaný a validovatelný,
- SRI ověřuje integritu externích zdrojů,
- minifikace zmenšuje soubory,
- obfuskace zhoršuje čitelnost, ale není skutečné zabezpečení.
