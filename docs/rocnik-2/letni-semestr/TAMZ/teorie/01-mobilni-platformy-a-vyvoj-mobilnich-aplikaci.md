# Mobilní platformy a vývoj mobilních aplikací

### Co je mobilní zařízení

Mobilní zařízení je malé přenosné výpočetní zařízení, typicky kapesní velikosti, které má vlastní vstupní a výstupní rozhraní. Nejčastěji se jedná o displej a dotykovou obrazovku, případně malou klávesnici nebo jiné senzory.

Typické příklady mobilních zařízení:

- smartphone,
- tablet,
- handheld herní konzole,
- navigace,
- IoT zařízení,
- chytré hodinky a další wearable zařízení,
- monitorovací a embedded zařízení,
- fotoaparáty a další přenosná elektronika.

Mobilní zařízení nejsou pouze telefony. Z pohledu vývoje aplikací je důležité, že se jedná o zařízení s omezenými zdroji, proměnlivým připojením a často s nestandardním ovládáním.

### Specifika mobilního vývoje

Vývoj pro mobilní zařízení má několik omezení a zvláštností, které se u desktopových aplikací řeší méně často.

Důležité rozdíly:

- menší displej,
- různé velikosti a poměry stran obrazovek,
- dotykové ovládání místo přesné myši,
- virtuální klávesnice,
- omezený výkon CPU a GPU,
- omezená kapacita baterie,
- proměnlivé nebo pomalé internetové připojení,
- časté přerušení aplikace uživatelem,
- rozdíly mezi platformami a prohlížeči,
- práce se senzory zařízení.

Mobilní aplikace proto musí být jednoduchá, rychlá, úsporná a dobře použitelná i na malém displeji.

### Co se v TAMZ I řeší

Předmět se zaměřuje hlavně na webové a hybridní technologie. Nejde primárně o nativní Android nebo iOS vývoj.

Hlavní oblasti:

- HTML,
- CSS,
- JavaScript / ECMAScript,
- DOM a BOM,
- HTML5 API,
- formuláře a mobilní UI,
- Canvas, SVG a 2D grafika,
- síťová komunikace,
- datové formáty,
- hybridní aplikace,
- Apache Cordova,
- základní bezpečnost a optimalizace.

Co se zde typicky neřeší do hloubky:

- nativní Android vývoj,
- Kotlin,
- Dart / Flutter,
- iOS vývoj,
- Xamarin,
- pokročilé frameworky typu React,
- desktopový JavaScript mimo kontext mobilních/webových aplikací.
