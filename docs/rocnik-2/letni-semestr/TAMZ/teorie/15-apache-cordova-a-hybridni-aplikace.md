# Apache Cordova a hybridní aplikace

### Co je Cordova

Apache Cordova umožňuje vytvářet mobilní aplikace pomocí HTML, CSS a JavaScriptu. Aplikace běží uvnitř nativního kontejneru, který obsahuje WebView.

Princip:

- UI je napsané jako webová aplikace,
- aplikace je zabalena jako nativní balíček,
- JavaScript může přes pluginy přistupovat k funkcím zařízení.

### Výhody Cordovy

- jeden kód pro více platforem,
- využití znalostí HTML/CSS/JS,
- rychlý vývoj prototypů,
- možnost přístupu k nativním funkcím přes pluginy,
- jednodušší tvorba hybridních aplikací.

### Nevýhody Cordovy

- nižší výkon oproti nativním aplikacím,
- závislost na WebView,
- problémy s kompatibilitou pluginů,
- rozdíly mezi platformami,
- složitější debugging některých nativních problémů.

### Typické použití

Cordova se hodí pro:

- jednodušší aplikace,
- interní firemní nástroje,
- formulářové aplikace,
- aplikace s webovým backendem,
- prototypy,
- aplikace, kde výkon není kritický.

Méně vhodná je pro:

- náročné hry,
- aplikace s intenzivní grafikou,
- aplikace vyžadující maximální nativní výkon,
- aplikace s komplikovanou integrací nativních API.
